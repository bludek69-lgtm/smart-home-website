🗃 Aplikace · Sbírka

Numismatika & Filatelie

Webová aplikace pro správu sbírky mincí, bankovek, poštovních známek a pohlednic. AI rozpoznávání z fotky, oceňování, exporty, přístup odkudkoli.

Přístup

Dvě verze

DEMO je veřejné a otevřené. PRIVATE je chráněné přihlášením — přístup jen pro vlastníka.

🌐 DEMO verze

Veřejná ukázková verze aplikace s fiktivními demo daty. Žádná reálná sbírka, žádné přihlášení — jen pohled na to, jak aplikace funguje.

Živá instance s reálnou sbírkou. Chráněna přihlášením přes Google + 2FA. Přístup pouze pro vlastníka po ověření identity.

Přihlásit se →

Co aplikace umí

Funkce

🪙 Katalog sbírky

Mince, bankovky, filatelie, pohlednice. Filtry podle kategorie, země, roku, stavu, AI confidence. Fulltext přes ID, motiv, text na kusu.

🤖 AI rozpoznávání

Fotka → AI návrh identifikace (typ, země, rok, nominál, motiv, stav, varianta). Každý návrh čeká na review — uživatel potvrdí, opraví nebo zamítne. AI nikdy sama nepřepíše potvrzená data.

💰 Oceňování

Orientační odhad low/mid/high se zdrojem a datem. Varování na staré ceny (starší 1 rok) a ceny bez ověřeného zdroje.

📤 Exporty

CSV, Excel (.xlsx), PDF seznam, ZIP archiv s fotkami. PRIVATE MODE only — žádná reálná data na GitHub.

Pod kapotou

Architektura

Stack

  • Frontend: HTML/JS (PapaParse pro DEMO CSV)
  • Backend: Python + FastAPI (PRIVATE MODE)
  • Databáze: SQLite — lokálně, nikdy na GitHub
  • AI: Vision API (OpenAI GPT-4o / Anthropic)
  • Export: openpyxl, fpdf2, zipfile

Bezpečnost

  • Reálná data nikdy mimo lokální PC
  • GitHub: pouze zdrojový kód + demo data
  • PRIVATE instance: Cloudflare Tunnel + Access
  • Auth: Google login + TOTP (Authenticator app)
  • Pre-commit scanner — blokuje privátní data
