04 — Dashboard

Tři obrazovky, jeden systém

Sdílená architektura, různá rozlišení. Každá varianta optimalizovaná pro jiný fyzický kontext — od kiosku v předsíni po pracovní monitor.

Co dashboard ukazuje

Zónové dlaždice — každá místnost má kartu se stavy zařízení, teplotou, světlem.
Audio mix — co hraje, kde, kdo má prioritu (rádio / TTS / scéna).
Health score — 0–100, viditelný v reálném čase, klesá při problémech.
Brain panel — výsledky denní Gemini analýzy + alerty.
TV remote overlay — full controls (D-pad, numpad, Home/Back, kanály, hlasitost).
Pomodoro timer — pracovna, 25/5 cykly s TTS oznámeními.
Sparkline grafy — spotřeba lednice, trouby, mikrovlnky (120 vzorků).
Weather 3-day — předpověď agregovaná z OWM.

Screenshoty výše ukazují statickou demo verzi dashboardu (offline mockup designu). Live verze běží lokálně přes Homey REST API a není přístupná zvenčí — to je záměr.
