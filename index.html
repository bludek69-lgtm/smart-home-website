What Makes This Different

Není to běžný smart home tutorial

Čtyři charakteristiky, kterými se SMART HOME OS odlišuje od typické smart home instalace.

📜

Script-First Architecture

Logika v HomeyScript skriptech, Flow karty jen jako triggery. 116 verzovatelných skriptů místo drag-and-drop chaosu.

🔁

Self-Healing Logic

Watchdogy detekují stuck states, auto-restart při memory leak, Stale Cleaner cron resetuje ghost values po 60 s. Systém se opraví sám.

🩺

AI Diagnostics

Gemini čte event log a navrhuje akce. Brain Guardian validuje expected vs actual state. Anomaly detection bez ML — pravidla a state machine.

🌱

Living Operating System

Dům není dokončený produkt. Každý týden commit, každý měsíc nová verze subsystému. Není to instalace, je to průběžná kultivace.
